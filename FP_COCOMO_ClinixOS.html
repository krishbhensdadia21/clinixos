Function Type Definitions:
  • ILF: User-identifiable group of logically related data maintained inside the system.
  • EIF: Data referenced by the system but maintained by an external application.
  • EI: Process that receives external inputs and updates internal logical files.
  • EO: Process sending derived data, reports or calculated results outside.
  • EQ: Process of immediate data retrieval without updating any internal file.

Step 5: COCOMO Equations & Final Calculations

Using KLOC = 10.834 in Semi-Detached Mode (a = 3.0, b = 1.12, c = 2.5, d = 0.35):

1. Effort Required (E):
E = a × (KLOC)b = 3.0 × (10.834)1.12
(10.834)1.12 = 14.78
E = 3.0 × 14.78 = E = 44.34 Person-Months (≈ 44.3 PM)

2. Development Time (Tdev):
Tdev = c × (E)d = 2.5 × (44.34)0.35
(44.34)0.35 = 3.96
Tdev = 2.5 × 3.96 = Tdev = 9.90 Months (≈ 9.9 Months)

3. Average Staff Size (SS):
SS = E / Tdev = 44.34 / 9.90 = SS = 4.48 Persons (≈ 4 to 5 Persons)

4. Productivity:
Productivity = KLOC / E = 10.834 / 44.34 = 0.244 KLOC / Month (244 LOC / PM)
Viva / Lab FAQ Section:
Q1: Why was Semi-Detached mode chosen over Organic mode?
Hospital management requires zero-downtime bed management, vital monitoring, prescription integrity, and strict access controls. Unlike casual organic utility software, ClinixOS involves medium complexity and moderate-to-high operational rigor.
Q2: What is the key difference between LOC and Function Points?
LOC measures the physical volume of written code (which fluctuates with language style and comments), whereas Function Points measure the actual business functionality delivered to the user. Here, 10,834 LOC yielded 255.30 FP.
Q3: How does SQLite impact estimation and portability?
SQLite runs in-process as an embedded file-based relational database. It eliminates separate database server maintenance overhead (reducing Installation Ease complexity) while guaranteeing full ACID transactions across all machines.
